# Диаграмма Ганта FRIDGE

[Открыть диаграмму в Microsoft Project — XML](FRIDGE_WBS_313.xml).

Диаграмма построена по всем 53 конечным задачам [WBS](WBS_hours.md). Общие трудозатраты — **313 чел.-ч**. У каждой задачи указаны код ИСР, исполнитель, трудозатраты, длительность, начало, окончание и предшественники.

Период проекта — **19 октября — 15 декабря 2026 года**. Подготовительные работы распределены с **19 октября по 25 ноября**, с занятостью до 3 часов 15 минут в будний день (08:00–11:15). Пустого промежутка между подготовкой и реализацией нет. Веха начала реализации закреплена за **26 ноября в 08:00**; после четырёх часов настройки окружения первые задачи программирования начинаются **26 ноября в 13:00**.

Расчётное завершение — **9 декабря в 11:00**, срок сдачи — **15 декабря**. С 26 ноября рабочий календарь — понедельник–пятница, 08:00–12:00 и 13:00–17:00. Выходные нерабочие. Назначения исполнителей не пересекаются; фактическая готовность задач в файле не проставлена.

Граф содержит **70 связей «окончание — начало»**. Из каждого узла выходит не более двух связей. Пять вех имеют нулевые трудозатраты: начало проекта, утверждение плана и требований, начало реализации, запуск frontend и завершение проекта. Технологические зависимости и порядок назначений исполнителей образуют единый связный граф.

XML открывается в Microsoft Project через **Файл → Открыть → Обзор** с выбором типа XML. При импорте используется вариант **«Как новый проект»**; затем проект можно сохранить в формате `.mpp`.

Файл `Project1.mpp` относится к архивной версии от 10 ноября. Актуальная диаграмма — XML по ссылке выше.
