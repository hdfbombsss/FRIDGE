# Поиск рецептов по имеющимся ингредиентам

Учебный проект: пользователь вводит продукты, которые есть дома (например, две картофелины, морковь и лук), а приложение предлагает подходящие рецепты и показывает недостающие ингредиенты.

## Состояние проекта

Сейчас подготовлены проектные артефакты и структура работы команды. Реализация приложения, выбор стека, полный CI и развёртывание ещё впереди. Документ не выдаёт плановые задачи за выполненные.

## Команда

| Участник | Подтверждённая роль |
|---|---|
| Пешков Никита | PM; фронтенд |
| Буглак Даниил | фронтенд |
| Ярмов Никита | аналитика; QA; UI/UX-дизайн |
| Сковороднев Денис | backend; Lead Dev; DevOps |

Функциональные теги в ИСР обозначают тип работы. Ответственные определяются по таблице выше: задачи `[Frontend / PM]` выполняет Пешков, остальные `[Frontend]` — Буглак; `[Backend]` и `[Lead Dev]` — Сковороднев; `[Аналитик]`, `[QA]` и `[Дизайнер]` — Ярмов. Задачи `[Вся команда]` выполняются совместно. Распределение можно пересмотреть после оценки навыков и загрузки.

## Ближайший результат

Вертикальный срез: ввести продукты, получить подборку из небольшой проверенной базы, открыть рецепт и увидеть, чего не хватает. Каждый модуль ведётся параллельно: требования и тест-кейсы готовятся вместе с реализацией frontend/backend, затем проверка и исправление багов.
